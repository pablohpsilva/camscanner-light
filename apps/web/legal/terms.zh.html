服务条款

ScannerCam Light 是一款适用于 iOS 和 Android 的免费文档扫描应用，全部在设备本机处理：扫描、编辑、文字识别和存储都在您的设备上完成；它没有广告，不需要用户账户，也不进行任何跟踪或数据分析。少数可选功能确实会与第三方联系，其中有些联系是自动发生的，而不是由您选择触发——隐私政策逐一说明了每一种情况。本条款规范您对本应用的使用。条款力求简明扼要，但仍然是您与 ScannerCam Light 开发者之间具有法律效力的协议。

数据丢失与备份

ScannerCam Light 仅将您的文档存储在您的设备上，形式为文件加一个本地数据库。不存在云端存储，也没有任何服务器端副本——本应用不会将您的文档备份到任何服务器。

扫描与 OCR 的准确性

ScannerCam Light 中的边缘检测、透视校正、图像增强和文字识别（OCR）均为自动化处理，并非完美无缺。它们可能会裁切、扭曲、误读或遗漏内容，在原件质量较差、版式不规则或为手写体的情况下尤为如此。文字识别还仅能读取拉丁字母文本——即英语、西班牙语、法语等语言所使用的字母——因此中文、阿拉伯文和西里尔文文本完全不会被识别，也不会变得可搜索。

在未与原件核对之前，不应将这些功能的输出结果用于法律、医疗、财务或其他有重大后果的用途。在依赖已扫描或已识别的文档、或将其发送给他人之前，请务必先进行核实。

第三方服务

ScannerCam Light 绝不会把您的数据交给任何人。本应用没有用户账户，从不询问您是谁，也不为您保存任何姓名、登录信息、广告标识符或个人资料——因此它根本没有任何身份可以交给别人。您扫描的任何内容都绝不会发送给下列任何一方，与您有关的任何信息也绝不会被出售、出租，或为广告及用户画像目的而共享。本应用确实会与少数几家独立的第三方发生接触，每一家都受其自身条款和隐私惯例的约束，ScannerCam Light 的开发者对此并无控制权。其中有些接触发生在您做出某项操作之后，有些则是自动发生的。各方能够获知什么、又是如何获知的，说明如下：

  • Cloudflare 与 GitHub 只涉及可选的反馈功能，而且仅限于启用了该功能的版本。在验证质询自动加载时，以及在消息被提交时，Cloudflare 会收到您设备的 IP 地址——任何服务器在您的设备与其联络时都会收到该地址——同时还会收到一项反滥用证明，该证明只是证实本应用是一个正版安装，而不是用来识别您的身份。GitHub 会收到您撰写的消息，以及您的电子邮件地址（仅当您选择填写时）。应用不会告诉它们中的任何一方您是谁：您填写的电子邮件地址是唯一能够识别您身份的信息，而它之所以会到达它们那里，也仅仅是因为您自己选择了填写它。

在使用涉及这些第三方的功能之前，请阅读它们各自的条款；而属于自动发生的那些联系——资料库页面打开时对反馈服务的检查、反馈表单打开时的验证质询，以及支持页面打开时向 App Store 发出的打赏选项查询——无需您另行做出选择便会发生。ScannerCam Light 的开发者不对其行为、疏漏、可用性或政策承担责任。
