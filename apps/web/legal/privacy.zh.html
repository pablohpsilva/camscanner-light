隐私政策

ScannerCam Light 是一款适用于 iOS 和 Android 的免费、离线、完全在设备本机处理的文档扫描应用。本政策说明本应用究竟会触及哪些数据、这些数据保存在哪里，以及极少数会有内容离开设备的情形。

生效日期: 2026-09-08

本译文仅供参考。如与英文版本存在冲突，以英文版本为准。

摘要

ScannerCam Light 的设计目标是让文档保持私密。您扫描的文档、从中识别出的文本，以及由此派生的一切内容，都保留在您的设备上，绝不会被上传。少数可选功能确实会使用网络，其中有些是自动发生的，而不是仅在您主动请求时才发生：在提供可选反馈功能的情况下，资料库页面打开时，应用就会检查反馈服务是否可访问；而打开反馈表单会加载一个 Cloudflare 验证质询，该质询会收到您设备的 IP 地址——这两件事都发生在您输入或发送任何内容之前。在提供应用内打赏的情况下，打开支持页面时，应用就会向 App Store 查询可用的打赏选项。下文的“网络访问”“反馈”以及“应用内购买与打赏”部分逐一说明了每一种情况。没有用户账户、没有数据分析、没有广告、没有跟踪，个人数据也绝不会被出售。

会收集哪些内容

几乎什么都不收集。 ScannerCam Light 没有用户账户，也没有任何形式的数据分析或跟踪；不显示任何广告，任何数据都绝不会被出售。任何文档、任何页面图像，以及从文档中识别出的任何文本，都绝不会被发送到任何服务器。真正离开设备的内容仅限于下文“网络访问”“反馈”以及“应用内购买与打赏”部分所述的几种情况：可选的反馈功能——包括它在提交任何内容之前自动发出的两个请求——在提供应用内打赏时向 App Store 查询可用打赏选项的请求，以及您点按的任何捐赠链接。

您的数据保存在哪里

  • 扫描的图像仅以文件形式存储在您的设备上。
  • 文档标题和文本保存在您设备上的本地数据库中。
  • 文字识别（OCR）完全在您的设备上运行——不会有任何图像或文本被发送到任何地方。

网络访问

除本部分所述的情况外，本应用不会自行发出任何网络请求——但其中有些情况是自动发生的，而不是由您触发的。以下情况会产生对外连接：点按可选的捐赠链接时，会在浏览器中打开一个第三方捐赠页面，该页面不受 ScannerCam Light 开发者控制，开发者也不会从中获取任何数据；在提供应用内打赏的情况下，打开支持页面时，应用就会向 App Store 查询可用的打赏选项，无论您之后是否真的打赏，而实际购买的网络部分则由 Apple 单独处理，详见下文“应用内购买与打赏”部分；以及，在提供可选反馈功能的情况下，与该功能相关的网络请求，详见下文“反馈”部分——其中包括资料库页面打开时对反馈服务是否可访问的检查，以及反馈表单打开时加载的 Cloudflare Turnstile 质询，这两者都不会等到您提交任何内容才发生。

在 Android 上，发布版应用完全不会请求 INTERNET 权限，因此无法发出任何网络请求；所以在发布版 Android 构建上，可选的反馈功能无法连接到它的服务，也不会在其中提供该功能。iOS 上没有对应的权限系统，而上述那些自动请求确实存在：反馈服务可访问性检查、Cloudflare Turnstile 质询，以及向 App Store 查询打赏选项，全都无需您触发便会发生。除了这些请求以及您自己点按的链接之外，本应用不会发出任何其他请求。

反馈

本应用包含一项可选的发送反馈功能。该功能仅在启用了它并且能够访问网络的构建中可用，因此发布版 Android 构建被排除在外——这些构建不会请求 INTERNET 权限，所以其中不会提供该功能。在提供该功能的情况下，在您输入任何内容之前会发生两件事：资料库页面加载时，应用会发出一个小请求，检查反馈服务当前是否可访问；而当您打开反馈表单本身时，表单内会加载一个 Cloudflare Turnstile 人机验证质询，这意味着此时 Cloudflare 会收到一个请求以及您设备的 IP 地址。这两个步骤都不会发送您的消息、邮箱，或任何有关您文档的信息——它们会自动发生，且不依赖于点击“提交”。

只有当您点按提交时，您的消息以及下列字段才会被发送：

  • 您的消息——在反馈表单中输入的文本（必填）。
  • 您的电子邮箱地址——仅在选择填写时才会发送。提供邮箱完全是可选的。
  • 非个人诊断信息——应用版本、操作系统版本、设备型号，以及语言/地区。这些信息有助于重现所报告的问题，且不包含关于您文档的任何信息。

点击提交后，这些数据会被发送到一个 Cloudflare Worker 服务，该服务会在应用的 GitHub 代码仓库中创建一个公开可见的 issue。这意味着您的消息文本将对互联网上的任何人可见，如果其中包含电子邮箱地址，该地址也会在这个 GitHub issue 中公开可见。

应用会在提交前对这种公开可见性发出提示。反馈消息中不应包含敏感信息，如果不希望邮箱地址被公开可见，可以将邮箱字段留空。

任何扫描文档或其内容都绝不会被发送。 反馈提交内容严格限于上述字段。

应用内购买与打赏

视您的平台和应用版本而定，iOS 上可能会提供可选的应用内打赏；而是否真的会出现打赏选项，还取决于 Apple 当时在 App Store 中的设置，因此支持页面完全可能一个选项都不显示。在提供打赏的情况下，打开支持页面时，应用就会向 App Store 查询可用的打赏选项，这发生在任何打赏之前，并且与是否真的打赏无关。打赏本身完全由 Apple 处理；开发者不会收到任何银行卡信息、账单地址或其他支付数据——只能获得 Apple 提供的汇总、匿名的销售报告。在 Android 上没有应用内购买；在确实提供捐赠方式的情况下，点按其链接会打开您的浏览器。

根据平台和应用版本的不同，还可能提供通过 Ko-fi 和比特币进行捐赠的选项。这些方式与任何 Apple 应用内购买无关，并且和其他捐赠链接一样，只会在您的浏览器中打开一个第三方页面。

分享

当文档被导出或分享时，目标位置是通过您设备自身的分享菜单选择的。该操作以及文件的去向，完全由您自己控制。

数据保留

扫描文档及其元数据会一直保留在您的设备上，只要您不删除它们——不会有任何内容被自动删除，也不会有任何内容自行过期。文档只有在您于应用内删除它，或您卸载应用本身时才会被移除。

卸载 ScannerCam Light 会移除本地数据库及其创建的所有图像文件；卸载后不会有任何内容留存。由于任何文档都从未在服务器端生成过副本，因此也就不存在可以请求删除的服务器端副本。在您的设备上删除会立即移除应用自身的文件和数据库记录；至于底层存储实际何时被覆写，则由您的操作系统和设备决定，本应用对此并无控制权。

您的权利

诸如欧盟/英国《通用数据保护条例》（GDPR）和《加州消费者隐私法案》（CCPA）等隐私法律赋予个人对其个人数据的权利，包括访问、更正、删除或反对处理这些数据的权利。

由于 ScannerCam Light 不会在任何服务器上收集或存储任何个人数据，因此通常没有任何内容需要导出、更正或删除：本政策所述的数据仅以文件和数据库的形式存在于您自己的设备上，始终处于您的直接掌控之下，您可以随时通过删除文档或卸载应用来移除这些数据。

主要的例外是通过应用内反馈表单自愿提交的反馈。该提交以您的同意作为法律依据：您的消息、邮箱和诊断信息会在您点按“提交”时被发送。而反馈功能在此之前发出的那些请求——见上文“反馈”部分——是自动发生的，并不以该同意为前提，其中一个请求还会在表单打开时向 Cloudflare 披露您设备的 IP 地址。已提交的反馈 issue 会成为一个公开的 GitHub issue；可以通过写信至下方的支持邮箱申请将其移除，但不承诺任何处理时限，而且到那时该 issue 可能已被他处复制、缓存或收录，对此 ScannerCam Light 的开发者无从撤销。

儿童隐私

本应用并非面向儿童，没有用户账户，不会询问任何人的年龄或其他个人信息，不显示广告，不包含任何数据分析或跟踪 SDK，也绝不会将扫描的文档发送到任何地方。不过，它在网络上并非完全静默：在提供可选反馈功能的情况下，资料库页面打开时，应用就会检查反馈服务是否可访问；而打开反馈表单会加载一个 Cloudflare Turnstile 质询，该质询会向 Cloudflare 披露设备的 IP 地址——这两件事都是自动发生的，无需任何人选择发送任何内容。这适用于任何年龄段的用户，并且就是在没有刻意操作的情况下所发生的全部内容。

本政策的变更

ScannerCam Light 的开发者可能会不时更新本政策，例如为了反映新功能或适用法律的变化。本文档顶部的生效日期显示了当前版本的生效时间。

本政策变更时，不会发送单独的通知。应用内附带的版本，反映的是构建该版本 ScannerCam Light 时的现行版本；最新版本以 ScannerCam Light 网站上发布的版本为准，上方的生效日期显示了您正在阅读的是哪个版本。
