常见问题

关于 ScannerCam Light 的常见问题解答。如需了解背后完整的法律细节，请参阅隐私政策和服务条款。

生效日期: 2026-09-08

本译文仅供参考。如与英文版本存在冲突，以英文版本为准。

它能离线使用吗？

可以。扫描、边缘检测、图像增强以及设备端文字识别（OCR）全部在设备本地运行，不需要任何网络连接。在 Android 上，发布版应用甚至不会请求 INTERNET 权限，因此它根本没有任何发出网络请求的方式。

在 iOS 上没有对应的权限系统，但对于与文档相关的一切来说情况是一样的——文档的任何内容都从不接触网络。在某个版本中启用了可选反馈功能的情况下，每次打开资料库页面时，应用都会自动检查反馈服务是否可访问，无论反馈功能是否被实际使用——具体这项检查会发送什么、何时发送，请见下方关于反馈的问题。在提供应用内打赏的情况下，打开支持页面时，应用就会向 App Store 查询可用的打赏选项，无论您之后是否真的打赏；实际购买的网络部分由 Apple 处理。

我的文档存储在哪里？

仅存储在设备上。扫描的图像以文件形式保存在应用自身的存储空间中，文档标题和提取出的文本则被索引到本地数据库中——不会上传到任何地方。有关存储内容及存储位置的完整说明，请参阅隐私政策。

它是免费的吗？

是的——ScannerCam Light 完全免费使用，且没有任何广告。根据平台和应用版本的不同，可能会提供一种可选的方式来支持本项目：在 iOS 上由 Apple 处理的应用内打赏、Ko-fi 链接，或比特币捐赠地址。这些方式均不会改变应用本身的功能。

打赏或捐赠能解锁什么？

什么都不会解锁。任何打赏或捐赠——无论是由 Apple 处理的可选应用内打赏、Ko-fi 支持，还是比特币捐赠，具体取决于提供了哪种方式——都完全是自愿行为，不会解锁任何功能、取消任何限制，也不会改变应用的行为方式。在任何打赏之前，ScannerCam Light 已经包含了它所提供的全部内容。

打赏和捐赠不可退款。完整条款请参阅服务条款。

如何导出 PDF？

打开一个文档，选择导出，然后选择 PDF。系统的分享面板随后会让您将该 PDF 保存、打印，或发送到那里选择的任意应用或目的地——ScannerCam Light 既不会控制也不会知道它最终去向何处。

文字识别（OCR）的准确度如何？

并不完美。文字识别与边缘检测、图像增强一样，都是自动化处理，可能会误读、遗漏或错乱文本——在原件质量较差、版式不规则或为手写体的情况下尤其如此。

在依赖识别出的文本之前，请务必将其与原件进行核对，对于任何法律、医疗或财务相关的用途尤其如此。完整的准确性免责声明请参阅服务条款。

搜索是如何工作的，它找不到什么？

搜索会检索文档标题以及设备端 OCR 捕获到的文本。由于 OCR 只能读取拉丁字母文字，内容为中文、阿拉伯文、俄文或其他非拉丁字母文字的文档，无法通过搜索其正文文字找到。但它的标题仍然可以搜索到，因为标题是直接匹配的，并不经过 OCR。

我的文档在任何地方有备份吗？

没有。ScannerCam Light 仅将文档存储在设备本地——不存在任何云存储，也没有应用创建的任何备份，也不会有任何内容被复制到服务器。如果应用被卸载，或设备丢失、被恢复出厂设置或损坏，这些文档将永久丢失。

请自行保留您承受不起丢失的任何内容的副本——例如，在卸载应用或更换设备之前，将重要文档导出到其他应用、电脑，或您选择的云服务中。有关数据丢失的完整条款，请参阅服务条款。

如何释放存储空间？

从资料库中删除不再需要的文档。删除一个文档会将其图像文件从设备上彻底移除，而不仅仅是从列表中移除条目，因此空间会被真正释放出来。

通过应用发送的反馈会被公开吗？

会——在提供可选反馈功能的情况下（该功能按构建启用，而发布版 Android 构建根本无法发出网络请求，因此其中不会提供该功能），提交的消息会在 ScannerCam Light 的 GitHub 代码仓库中变成一个公开可见的 issue，互联网上的任何人都能读到这条消息的文本，以及（如果填写了的话）电子邮箱地址。

在此之前也会发生一些网络活动：资料库页面加载时，应用会检查反馈服务是否可访问；而打开反馈表单会加载一个 Cloudflare Turnstile 人机验证质询——这意味着 Cloudflare 会收到一个请求以及设备的 IP 地址。这两个步骤都不会发送消息或邮箱地址；那要等到点按提交时才会发生。

任何扫描文档或其内容都绝不会被包含在反馈中。可以将邮箱字段留空，以避免其出现在公开的 issue 中；也不应在消息本身中包含敏感信息。完整细节请参阅隐私政策的反馈部分。

应用支持我的语言吗？这是否也包括 OCR 和搜索？

应用界面已翻译为 11 种语言，包括中文、俄文和阿拉伯文。文字识别的支持范围更有限：ScannerCam Light 中的 OCR 只能读取拉丁字母文字——即英语、西班牙语、法语等语言所使用的字母——而无法读取中文、阿拉伯文或西里尔字母文字。

由于全文搜索建立在 OCR 输出结果之上，这一限制同样会影响到搜索：以中文、阿拉伯文或俄文扫描的文档，无法通过搜索其正文文字找到，但其标题仍然可以被搜索到。扫描、查看和导出此类文档均可正常进行——只有文字识别和文字搜索会受到影响。

ScannerCam Light 会显示广告或追踪使用情况吗？

不会。本应用中任何地方都没有广告、分析、崩溃报告或追踪 SDK，也没有用户账户，您扫描的任何内容都绝不会被发送到任何地方。但这与本应用在网络上完全静默并不完全是一回事：在提供可选反馈功能的情况下，资料库页面打开时，应用就会自动检查反馈服务是否可访问；而打开反馈表单会联系 Cloudflare，后者会收到设备的 IP 地址。这两个请求会让其运营方知道某台设备在某个时间、从某个 IP 地址打开了某个页面；ScannerCam Light 的开发者不会据此建立任何画像，也不会出售任何内容。有关应用在数据方面具体会做和不会做什么的完整说明，请参阅隐私政策。

如果我丢失了手机，我的文档会怎样？

文档会永久丢失。ScannerCam Light 只将文档保存在扫描它们的那台设备上——不存在云端副本，也没有账户可用来在另一台设备上重新登录。如果手机丢失、被恢复出厂设置或损坏，或应用被卸载，其文档既无法由 ScannerCam Light 的开发者找回，也无法由任何其他人找回。

唯一的保护方式是提前将重要内容导出副本——导出到其他应用、电脑，或您选择的云服务。有关数据丢失的完整条款，请参阅服务条款。

我该如何联系你们？

如有问题、错误报告或反馈，请发送邮件至 scannercamlight.line149@passmail.net。在启用的情况下，应用内的发送反馈表单是报告问题的另一种方式——该功能会发送什么内容、发送给谁，请参阅隐私政策；管辖应用使用的条款，请参阅服务条款。
